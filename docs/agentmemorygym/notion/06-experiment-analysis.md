# 实验分析设计

## 目标

实验分析要回答：AgentMemoryGym 的收益到底来自有效记忆，还是来自长上下文、固定检索、任务本身容易、或过度工具调用。

## 分桶分析

- 交互轮数：短程 / 中程 / 长程。
- 会话跨度：单会话 / 多会话 / 长间隔多会话。
- 依赖距离：当前动作依赖最近信息、早期信息或多跳信息。
- 任务类型：电商、旅行、搜索、形式化推理。

## Memory 行为指标

- 写入频率、写入时机、写入准确率。
- 更新是否覆盖冲突旧信息。
- 删除是否减少过时/错误记忆。
- 检索命中率和噪声率。
- 摘要是否保留关键约束。
- 检索后是否真的使用关键记忆。

## Ablation

- 移除 LTM。
- 打乱 retrieved memory。
- 删除关键早期 memory。
- 固定检索 top-k。
- 禁止 UPDATE/DELETE。
- 增加 memory operation cost。

## 方法设计门槛

v0 先跑标准 PPO/GRPO 类训练和基线。如果分析显示最终奖励无法稳定归因给早期 memory action，再考虑 credit-assignment 或 memory-state shaping 方法。新方法必须由失败模式驱动，不提前写成主贡献。
